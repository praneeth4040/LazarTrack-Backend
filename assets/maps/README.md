# Blank Map Reference Templates

Store clean, high-resolution blank overhead map images here for player path tracing and projection.

### Supported / Standard Free Fire Maps:
- `bermuda.png` (or `.jpg`)
- `purgatory.png`
- `kalahari.png`
- `solara.png`
- `nexterra.png`

### Requirements:
- Clean 1:1 square aspect ratio (e.g. 1024x1024 or 2048x2048).
- Free of player markers or dynamic route lines.
